# Archived ADRs and history

Superseded and retired ADRs, and the replaced text of amended ADRs. Current
decisions are in the [ADR index](../README.md); an accepted ADR there states
what is true now, and its `**History:**` line links its history file here.

The root `.ignore` hides this directory from `rg` and `fd`; use `rg -u` or
`fd -u` to search it (`git grep` searches it regardless).
